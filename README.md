# Smart Greenhouse Environment Monitor (Arduino)

An embedded C/C++ system built on Arduino to automate environmental monitoring and climate control within a greenhouse ecosystem.

## Features
- **Environmental Sensing:** Monitors real-time ambient temperature and humidity threshold changes.
- **Visual Feedback & Alerting:** Status LEDs/indicators trigger based on sensor thresholds (e.g., high temperature/humidity warnings).
- **Automated Control Logic:** Implements feedback loops to manage climate conditions for optimal plant growth.

## Tech Stack & Hardware Design
- **Software:** C/C++ (Arduino IDE)
- **Simulation & Schematics:** Designed and virtually verified via Tinkercad before hardware assembly.
- **Hardware Components:** Arduino Microcontroller (Uno/Nano), Temperature & Humidity Sensor, Status LEDs.
